# 常见峡谷播报：何时听到，何时看到

这里区分两件事：**公开对局资料里的常见叫法**，以及**《岚境》的实际触发规则**。本作内嵌 34 条独立语音，均为本机重新合成的配音，没有下载或提取官方音轨。

| 场景 | 《岚境》会说什么 | 屏幕上方 |
|---|---|---|
| 进入峡谷 → 出兵倒计时 → 第一波兵线出发 | 中文欢迎词、五秒提醒、全军出击 | 只播声音，不弹文字 |
| 普通击杀 | 自己击杀、自己阵亡、队友击杀、队友阵亡各有一条英文，见下方试听 | 两侧是双方头像，中间只保留中文结果；败者头像划红色笔锋 |
| 全场第一次英雄击杀 | First Blood | 第一滴血 |
| 短时间连续击杀 | 二至五杀，敌方连杀带 Enemy 前缀 | 二连击破至五连绝世 |
| 同一条命累计击杀 | 三至七杀及以上分五档，从 Killing Spree 到 Legendary；区分双方 | 对应连杀称号 |
| 击败已有连杀的英雄 | Shut Down | 终结 |
| 防御塔、小兵或野怪击败英雄，未归功给敌方英雄 | Executed | 显示真实击败者 |
| 一方五人同时阵亡 | Aced | 团灭提示 |
| 防御塔被拆、基地水晶被拆 | 英文拆塔／失塔、胜利／失败 | 防御塔战报／结算页 |
| 请求集合 | 中文队伍信号 | 集合提示，不盖住击杀卡 |

**普通击杀试听**：[自己击杀](../assets/audio/playerkill.wav) · [自己阵亡](../assets/audio/playerdeath.wav) · [队友击杀对手](../assets/audio/allykill.wav) · [队友被击杀](../assets/audio/enemykill.wav)。

本作以 10 秒作为相邻击杀的连击窗口；死亡清空连击和连续击杀计数。同一次击杀优先选首杀、连击、终结、连续击杀称号，最后才是普通人称播报，不把同一次击杀念两遍。团灭是单独的全队事件。这些数值和优先级是本作的实现，并非官方版本数据。

**整理依据：**[开场语音实例](https://www.bilibili.com/video/BV1Bm4y137ju/)用于核对欢迎、倒计时和出兵的顺序；[普通击杀的四种人称](https://www.yikajinfu.com/gonglue/232768285.html)用于区分本人和队友；[常见击杀、连杀、塔和团灭播报整理](https://www.bilibili.com/read/cv18025012/)用于交叉核对事件分类。公开资料未提供适用于所有赛季和模式的官方横幅规则；表中最后一列描述的是本作。
